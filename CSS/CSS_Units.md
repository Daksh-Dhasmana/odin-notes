## CSS Units ##

# 1.rem #
- Scalable unit.
- Root Em.
- Based on font size of html elements(usually 16px).
- Industry standards for padding, margins etc. Allows user to scale your site if they have vision needs.
- 1rem=16px, 2rem=32px.

# 2.% #
- Container.
- Percentage.
- a percentage of parent element's size.
- used for layouts.

# 3.vw #
- Viewport Width.
- Ignores parent and looks directly at screen.
- 1vw=1% of browser's width.
