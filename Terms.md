# Some important terms for Web Dev
## 1) Runtime Environment ##
- It is the "stage"/"ecosystem" where your code actually runs while program is executing.
- Eg: Web Browsers, Node.js

## 2) Web API Object ##
- Web API Object gives JS code access to platform capabilities like fetching APIs, document manipulations etc.
- We call it object because when you use it in JS, It takes form of an object- a container with properties(data) and method(functions).

## 3) Throughput ##
- Throughput is the amount of work or data a system processes within a given window of time
