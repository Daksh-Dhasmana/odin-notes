# Component Library
- A component library is a pre-packaged collection of reusable UI elements—such as buttons, text inputs, dropdown menus, modals, and navigation bars—that developers can import directly into their applications instead of building them from scratch.
- But we can also use Tailwind CSS or Bootstrap CSS for more personalized styling.
- Some component libraries are Material UI, Radix, Chakra UI.
