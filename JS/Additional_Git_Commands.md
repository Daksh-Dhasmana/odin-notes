# git commit --amend -m "[commit_message]"
- Is used to modify most recent commit in your git history
- NOTE: It doesn't edit the old commit, it creates a brand new commit and replaces it with old one
  
# git log
- Running git log prints a list of all the commits made in your repository, starting from the most recent one. It shows you the unique commit ID (SHA hash), the author, the date, and the commit message.
